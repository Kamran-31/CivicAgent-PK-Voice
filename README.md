# CivicAgent PK — Voice-to-Text Complaint Module

## Overview

The Voice-to-Text Complaint Module is a component of CivicAgent PK,
an autonomous public grievance and legal workflow engine designed
to help Pakistani citizens submit and process public complaints.

This module converts citizen voice complaints into text using
Groq's Whisper Large V3 speech-to-text model.

## Features

- Direct microphone recording
- Audio file upload
- Urdu speech transcription
- English speech transcription
- Mixed Urdu-English speech support
- Automatic language handling
- Audio validation
- API error handling
- Structured transcription output
- Downloadable transcription
- Streamlit web interface

## Supported Formats

- MP3
- WAV
- M4A
- WEBM

## Technology Stack

- Python
- Streamlit
- Groq API
- Whisper Large V3
- python-dotenv
